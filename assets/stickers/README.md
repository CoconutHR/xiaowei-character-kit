# 贴纸与表情包

当前收录 [xiaowei-sticker-draft-sheet-v1.png](xiaowei-sticker-draft-sheet-v1.png)：1254 × 1254 的 **3 列 × 3 行九宫格草案**，含真实透明像素、白色描边及光晕。

关联模板为 [Prompt 07 与单张贴纸模板](../../prompts/xiaowei-character-prompt-kit.md)。当前图板没有拆分为 9 个独立文件，也未通过任何聊天平台的尺寸、体积、背景和内容审核。

推荐先挑选一格，再同时上传母图与该格的副本，使用单张模板生成一个独立贴纸。若裁切现有副本，保留原图、记录裁切矩形与修改，不覆盖草案。跨格装饰、白边和透明区域需单独检查。

可添加文字版本，但建议保留无字底图，便于不同语言社区复用；字体必须有合法来源和相应使用许可。

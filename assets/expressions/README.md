# 表情素材

当前收录 [xiaowei-expression-sheet-v1.png](xiaowei-expression-sheet-v1.png)：**4 列 × 3 行，共 12 格表情参考**，1254 × 1254，含真实透明像素。

关联提示词为 [Prompt 04](../../prompts/xiaowei-character-prompt-kit.md)，但具体情绪以实际图片为准。当前没有拆分独立表情，也没有动画时序。

需要单张成品时，可选一格作为辅助参考，再上传母图生成独立图；或在副本上裁切并新增派生文件，保留原图及裁切记录。不要把有限像素的裁片等同于重新生成的高清素材。

新文件可命名为 `xiaowei-happy-v1.png`、`xiaowei-thinking-v1.png`，并更新 [素材清单](../manifest.json)。

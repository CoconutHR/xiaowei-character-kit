# 动作与助手状态素材

- [xiaowei-action-sheet-v1.png](xiaowei-action-sheet-v1.png)：**4 列 × 2 行，8 个全身动作**，1254 × 1254，关联 Prompt 05。
- [xiaowei-assistant-state-sheet-v1.png](xiaowei-assistant-state-sheet-v1.png)：**3 列 × 2 行，6 个半身状态**，1254 × 1254，关联 Prompt 06。

图板均含真实透明像素，尚未拆分。它们是静态表现参考，不是连续动画或已经按平台验收的状态资源。原提示词中的 `2-by-4` / `2-by-3` 表述已在项目副本中明确为行列数量，实际原图布局如上。

状态符号存在生成偏差：例如聆听格使用圆环而非原设定的声波。接入应用时按实际表情与图形解释，必要时重新生成指定状态，不自动承诺六格一一满足产品需求。

独立动作建议用 `xiaowei-wave-v1.png` 等名称；独立状态可按 `idle/`、`listening/`、`thinking/`、`working/`、`success/`、`needs-attention/` 分类。不要直接裁同宽网格就认定肢体和光晕不跨格，裁后需人工检查。

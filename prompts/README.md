# 提示词目录

[xiaowei-character-prompt-kit.md](xiaowei-character-prompt-kit.md) 包含初始 12 组提示词与单张贴纸模板。

## 复现已定稿角色

- 使用项目内的 [标准母图](../assets/reference/xiaowei-master-v1.png)，不要重新运行 Prompt 01 另选母图。
- 母图优先于文字、色值、辅助三视图或细节板。
- 先选择一个清晰任务：表情、动作、状态、贴纸、头像或主题图；数量、行列、比例和背景单独说明。
- 现有图板的关联模板不是逐图原始生成记录；平台设置与后期历史未记录，不保证相同文字能精确重现原文件。
- 模型标签 `GPT Image 2.5 Sunburst` 来自维护者原对话，不作为已验证的模型 API 标识；其他支持参考图的工具也可使用这些描述。

本次在项目副本补充了既有素材用法、母图优先规则，并修正发夹“奶油白气泡、绿边与三个绿点”、卫衣“奶油白袖身、绿色袖口”和图板行列的歧义。个人源目录的提示词文件没有修改。

## 新模板建议记录

用途、输入参考图、核心锚点、输出数量和比例、真实透明要求、允许变化、已测试工具、完整参数及已知偏差。不要将透明通道、贴纸白边和画面背景混为一谈。
